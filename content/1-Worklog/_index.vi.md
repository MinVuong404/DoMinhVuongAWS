# Nhật ký công việc thực tập

Nội dung nhật ký công việc phản ánh tiến độ 8 tuần thực tập tập trung tại Văn phòng AWS Hà Nội trong chương trình First Cloud AI Journey và 4 tuần mở rộng từ tuần 9 đến tuần 12.

---

### Danh sách các tuần thực tập

* Tuần 1, từ 03/08/2026 đến 09/08/2026: [Khởi tạo môi trường, quản trị định danh IAM và nền tảng AWS Cloud](1.1-week1/)  
  Kích hoạt xác thực đa yếu tố cho tài khoản Root, thiết lập tài khoản IAM theo nguyên tắc đặc quyền tối thiểu, cài đặt AWS CLI v2 và tạo cảnh báo kiểm soát ngân sách qua CloudWatch và AWS Budgets.

* Tuần 2, từ 10/08/2026 đến 16/08/2026: [Khảo sát dịch vụ cốt lõi và nghiên cứu kiến trúc Serverless](1.2-week2/)  
  Đánh giá 8 dịch vụ AWS cơ bản, so sánh mô hình máy chủ ảo EC2 và hàm Lambda, xác định cấu trúc giải pháp phi máy chủ.

* Tuần 3, từ 17/08/2026 đến 23/08/2026: [Kiến trúc giao tiếp mạng và cổng Amazon API Gateway v2](1.3-week3/)  
  Phân tích mô hình mạng, thiết lập Amazon API Gateway v2 chuẩn HTTP API, so sánh hiệu năng giữa REST API và HTTP API, xử lý cơ chế chia sẻ tài nguyên CORS.

* Tuần 4, từ 24/08/2026 đến 30/08/2026: [Đóng gói mô hình học máy bằng Docker Container và Amazon ECR](1.4-week4/)  
  Xuất tệp trọng số mô hình XGBoost và TruncatedSVD, viết Dockerfile dựa trên Amazon Linux 2023 và đẩy Container Image lên Amazon ECR.

* Tuần 5, từ 31/08/2026 đến 06/09/2026: [Triển khai hàm AWS Lambda Container và tối ưu độ trễ suy luận](1.5-week5/)  
  Tạo hàm Lambda sử dụng Container Image từ ECR, cấp phát bộ nhớ 512 MB, xử lý cơ chế nạp mô hình vào bộ nhớ đệm và đạt độ trễ Warm Start dưới 15 ms.

* Tuần 6, từ 07/09/2026 đến 13/09/2026: [Tích hợp cơ sở dữ liệu Amazon DynamoDB và dịch vụ cảnh báo Amazon SNS](1.6-week6/)  
  Thiết kế bảng DynamoDB lưu vết nhật ký kiểm toán, cấu hình SNS Topic gửi thông báo email khi phát hiện email nghi vấn có độ tin cậy từ 90% trở lên.

* Tuần 7, từ 14/09/2026 đến 20/09/2026: [Phát triển tiện ích Chrome Extension và kiểm thử trên Gmail](1.7-week7/)  
  Xây dựng tiện ích mở rộng trích xuất nội dung từ DOM Gmail, kết nối điểm cuối HTTPS của API Gateway và thực hiện kiểm thử với các mẫu email an toàn và độc hại.

* Tuần 8, từ 21/09/2026 đến 27/09/2026: [Thiết lập hệ thống giám sát với Amazon CloudWatch và tổng kết dự án](1.8-week8/)  
  Tạo bảng điều khiển giám sát CloudWatch Dashboard, thiết lập cảnh báo đo lường thời gian thực thi, tổng kết số liệu và hoàn thiện báo cáo giai đoạn 8 tuần.

* Kế hoạch mở rộng từ tuần 9 đến tuần 12: [Lộ trình hoàn thiện hệ thống cấp doanh nghiệp](1.9-future-weeks/)  
  Kế hoạch cấu hình AWS WAF chống tấn công từ chối dịch vụ, xây dựng đường ống dữ liệu với Amazon S3 và tự động hóa quy trình huấn luyện lại mô hình trên Amazon SageMaker.
