# 6.1. Competition Overview & Registration Roadmap

### 1. Introduction to "Prove It: Agentic Cloud Investigation Series"
The **Prove It: Agentic Cloud Investigation Series** is an advanced global competitive arena engineered by AWS, simulating catastrophic cloud outages, sophisticated intrusion attempts, and complex enterprise misconfigurations.

* **Format:** Time-pressured scenario challenges executed within isolated live AWS Sandbox accounts.
* **Core Competencies Evaluated:** Deep architectural troubleshooting, forensic analysis utilizing AWS CloudTrail and VPC Flow Logs, and automated programmatic remediation via AWS CLI and Python Boto3 scripts.
* **3-Phase Challenge Structure:**
  * **Day 1: Govern:** Implementing proactive identity boundaries, auditing IAM policies, and discovering privilege escalations.
  * **Day 2: Investigate:** Cloud forensic investigation, mapping adversary lateral movement across VPC subnets, and containing breaches.
  * **Day 3: Prove It Arena:** Live competitive arena resolving multi-region service disruptions and securing critical data lakes under strict time limits.
